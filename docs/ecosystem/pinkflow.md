# PinkFlow

**PinkFlow** is the test automation and orchestration platform for the MBTQ ecosystem.

- **Repository**: [github.com/pinkycollie/pinkflow](https://github.com/pinkycollie/pinkflow)

## Components

- **Test suites** — automated testing for MBTQ ecosystem services
- **Webapp** — model testing UI, caption testing
- **Orchestration** — coordinates DeafAUTH, Fibonrose, and PinkSync
- **Innovation hub** — Deaf-first innovation workflows

## Relationship to MBTQ.dev

PinkFlow handles orchestration and testing across the ecosystem, ensuring all services (DeafAUTH, Fibonrose, PinkSync) integrate correctly and meet accessibility standards.
